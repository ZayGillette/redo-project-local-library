# redo-project-local-library
Project Local Library Redo

# Coding Choices
For this project, I used .map, .find, .sort, .filter and .toLowerCase to work through my functions. These were all required in different situations for me to get the desired results. I also used a template literal, ternary operator and arrow functions.

# Implementation Plan
The plan was to go through each problem and use the hints provided to get all of the tests to pass when I ran them on Qualified. I kept files from all of my previous qualified tests and used my course modules as a reference when going through each problem to make sure I was structuring my code correctly.

# Navigation Structure
Clicking on the 'Overall Stats' link should show different metrics for the library, like Most Popular Books and Most Popular Authors.
Clicking 'Stats By Book' will show a list of all the books that have been returned and the ones that have been loaned out.
Clicking 'Stats By Account' will show each account the library has, along with the user's general information and the number of times they've borrowed.

# Coding Trade Offs
No trade offs used. Other than adding my functions, I kept everything else the same.

# Debugging and Troubleshooting Moments
I had a few syntax errors that came up when I ran tests on my code, but I was able to read the errors on Qualified and resolve them. I had a few extra brackets and parentheses where they didn't need to be.

# AI Usage
I didn't have to use AI since I was able to use the hints provided along with referring to my previous assessment files and modules to get the results I needed.

# Summary of Project Process
This was a pretty straightforward process for me. I followed the instructions that were given in qualified along with the hints provided in the documents to complete it all. I had previous tutoring sessions that helped me become familiar with the concepts of using arrow functions, maps and filters. I find these methods are much more efficient than using the longer functions I was using before. I also like how convenient it is to use template literals, which I used to get the full account names. I used the ternary operator when I needed to sort accounts by the last name. I remembered from a previous lesson that using .toLowerCase is good when it comes to sorting names so that they can all be sorted properly. All in all, it was a good project to test what I know about Javascript.
